# 点菜 · 私人菜单

一个给自己用的「饭店点菜」小应用：按分类挑菜、加购物车、写备注、下单，
下单后自动按菜生成**采购清单**，买一样勾一样。

- 纯静态页面，没有后端、没有账号、不联网也能打开（局域网内）
- 数据只存在手机浏览器里，不上传任何服务器
- 已经塞了 36 道家常菜当示例，随便删改
- 支持给菜加照片、关掉价格显示、导出/导入备份（备份含照片）

> **在线版**：<https://luv06511.github.io/diancai/>
> 手机打开这个地址就能用，可以直接"添加到主屏幕"。HTTPS 下 Service Worker 生效，
> 断网也能打开，不用开电脑。数据仍然只存在你自己的手机里。

> **Android 安装包**：[点菜 1.0 APK](https://github.com/Luv06511/diancai/releases/tag/v1.0-apk)
> Android 7.0 及以上，装完是桌面上的一个 App，完全离线，不需要电脑也不需要网络。
> APK 里的数据与上面两个网页版**互相独立**，迁移请用「设置 → 导出备份 / 从备份恢复」。

## 一、怎么打开

### 电脑上试

双击 **`启动.cmd`**。会弹出一个黑窗口（**别关它**，关了就停了），
浏览器会自动打开 `http://localhost:8000/`。

### 手机上用

1. 手机和电脑连**同一个 WiFi**
2. 看黑窗口里那行 `手机打开： http://192.168.x.x:8000/`
3. 在手机浏览器地址栏输入这个地址

第一次打不开，多半是 Windows 防火墙——允许一下 Python 就行。
（这台机器上已经有一条允许规则了，一般不用再动。）

### 加到主屏幕（像 App 一样）

- **iPhone（Safari）**：分享按钮 → 添加到主屏幕
- **安卓（Chrome）**：右上角 ⋮ → 添加到主屏幕

之后从主屏幕点开就是全屏，没有地址栏。

> 注意：局域网是 `http://`，所以浏览器不给离线缓存。手机和电脑要在一起、电脑开着服务，
> 才能打开。想彻底摆脱电脑，见文末「想更进一步」。

## 二、怎么用

| 页面 | 能干什么 |
| --- | --- |
| **点菜** | 顶部按分类筛；点 `+` 加一份；点卡片看食材和耗时；🎲「帮我配一桌」随机配一荤一素一汤一主食 |
| **购物车** | 改数量、每道菜单独写口味备注（少辣、不要葱）、整单备注（七点开饭）、下单 |
| **订单** | 每单有编号和时间；「做好了」打勾；「采购清单」；「再来一单」；删除 |
| **菜单** | 新增 / 编辑 / 下架（下架只是不显示，记录还在） |
| **设置** | 改菜单名字、开关价格、看统计、备份与恢复 |

几个细节：

- **采购清单**：按菜分组列出食材，勾掉的会划线，右上角显示 `已买/总数`。勾选状态会保存。
- **价格**：默认显示。关掉之后点菜页、购物车、订单里都不会再出现金额，只剩菜名和耗时。
- **照片**：编辑菜品时可以选一张图，会自动压缩到 880px 存进手机的 IndexedDB；不传就用表情。
- **售罄/下架**：下架的菜在点菜页是灰的，点 `+` 会提示「今天不做了」。

## 三、数据在哪、怎么备份

- 菜单、订单、购物车 → 浏览器 `localStorage`
- 菜品照片 → 浏览器 `IndexedDB`
- 都在**你自己手机的这个浏览器**里，不上传。

**换手机 / 清缓存 / 换浏览器之前**：
设置 → 「导出备份（JSON）」，会下载一个 `点菜备份-日期.json`，**照片也在里面**。
到新设备打开应用 → 设置 → 「从备份恢复」→ 选这个文件。

> 备份文件是这个应用唯一的「数据出口」，建议每个月导一次，扔网盘里。

## 四、常见问题

**手机打不开网址？**
1. 手机和电脑是不是同一个 WiFi（不是的话用热点也行，电脑连手机热点）
2. 电脑上那个黑窗口还开着吗
3. 防火墙拦了：控制面板 → Windows Defender 防火墙 → 允许应用通过 → 勾上 Python
4. 电脑休眠了：电源设置里关掉自动睡眠，或者用的时候叫醒它

**电脑的 IP 变了，数据是不是没了？**
数据没丢，但浏览器按「地址」隔离存储：IP 一变，旧数据还在旧地址下，新地址看到的是空的。
解决办法（任选）：
- 在路由器里给这台电脑绑定固定 IP（推荐，一次搞定）
- 或者用备份恢复一下

**端口 8000 被占了？**
`serve.py` 会自动往后找 8001、8002……看窗口里打印的实际地址就行。
也可以手动指定：`python serve.py 9000`。

**想让全家人都能点？**
现在是一台设备各存各的。要做「多手机同步点菜」得加后端，那是另一个量级的活，需要的话再说。

## 五、文件说明

```
diancai/
├─ index.html            页面骨架
├─ assets/
│  ├─ app.css            全部样式（浅色/深色自适应）
│  ├─ app.js             全部逻辑（无依赖）
│  ├─ seed.js            36 道示例菜
│  └─ icons/             图标（手机主屏幕用）
├─ manifest.webmanifest  PWA 配置
├─ sw.js                 Service Worker（联网走网络，断网用缓存）
├─ serve.py              本地静态服务（会打印手机可用的地址）
├─ 启动.cmd            双击启动
├─ gen_icons.py          重新生成图标（改设计才用得到）
└─ README.md             本文件
```

改代码不用重启服务，刷新页面就生效（`serve.py` 发的是 no-store）。
