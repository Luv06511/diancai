# 小饭桌 · 两个人一起

一个只有你俩会用的「今天吃什么」小本子：挑几道想吃的，记下来，顺手生成买菜清单。

- 没有价格、没有下单、没有商家那一套，就是两个人商量吃什么
- 纯静态页面 + 一个 Android 外壳，**完全离线**，数据只存在自己手机里
- 已经放了 36 道家常菜当底子，随便删改
- 可以给菜加照片、导出/导入备份（备份含照片）

> **在线版**：<https://luv06511.github.io/diancai/>
> 手机打开就能用，可以直接"添加到主屏幕"，断网也能开。

> **Android 安装包**：[小饭桌 APK（最新版）](https://github.com/Luv06511/diancai/releases/latest)
> Android 7.0 及以上，装完是桌面上的一个 App。APK 里的数据和网页版**互相独立**，
> 迁移请用「我们 → 导出备份 / 从备份回来」。

## 一、怎么打开

### 电脑上试

双击 **`启动.cmd`**。会弹出一个黑窗口（**别关它**，关了就停了），
浏览器会自动打开 `http://localhost:8000/`。

### 手机上用

1. 手机和电脑连**同一个 WiFi**
2. 看黑窗口里那行 `手机打开： http://192.168.x.x:8000/`
3. 在手机浏览器里输入这个地址

第一次打不开，多半是 Windows 防火墙——允许一下 Python 就行。

### 加到主屏幕（像 App 一样）

- **iPhone（Safari）**：分享按钮 → 添加到主屏幕
- **安卓（Chrome）**：右上角 ⋮ → 添加到主屏幕

## 二、四个页面

| 页面 | 能干什么 |
| --- | --- |
| **想吃** | 按分类挑菜，点 `+` 加一份；点卡片看食材和耗时；🎲「随便配一桌」随机配一荤一素一汤一主食 |
| **记录** | 每次「定啦」都会记一顿：第几顿、时间、吃了什么、小纸条；做好了打个勾，还能「再做一次」 |
| **菜谱** | 加菜 / 改菜 / 「歇一天」（先不出现在想吃里） |
| **我们** | 改小饭桌名字、看看一起吃过多少、备份与恢复 |

几个小细节：

- **想吃清单**：每道菜可以单独写小要求（少辣、不要葱），也可以留一句想说的话。
- **买菜清单**：按菜分组列食材，买一样勾一样，勾掉的会划线。
- **照片**：改菜时可以选一张图，会自动压缩存进手机；不传就用表情。
- **歇一天**：不想做的菜先藏起来，随时叫回来。

## 三、数据在哪、怎么备份

- 菜谱、记录、想吃清单 → 浏览器 `localStorage`
- 菜品照片 → 浏览器 `IndexedDB`
- 都在**你自己手机的这个浏览器/App** 里，不上传。

**换手机 / 清缓存 / 换浏览器之前**：
「我们 → 导出备份」，会下载一个 `饭饭备份-日期.json`，**照片也在里面**。
到新设备打开应用 → 「从备份回来」→ 选这个文件。

## 四、常见问题

**手机打不开网址？**
1. 手机和电脑是不是同一个 WiFi
2. 电脑上那个黑窗口还开着吗
3. 防火墙拦了：控制面板 → Windows Defender 防火墙 → 允许应用通过 → 勾上 Python
4. 电脑休眠了：电源设置里关掉自动睡眠

**电脑的 IP 变了，数据是不是没了？**
数据没丢，但浏览器按「地址」隔离存储：IP 一变，旧数据还在旧地址下。
最简单的办法是在路由器里给这台电脑绑定固定 IP；真变了，用备份恢复一下。

**端口 8000 被占了？**
`serve.py` 会自动往后找 8001、8002……看窗口里打印的实际地址。

## 五、文件说明

```
diancai/
├─ index.html            页面骨架
├─ assets/
│  ├─ app.css            全部样式（浅色/深色自适应）
│  ├─ app.js             全部逻辑（无依赖）
│  ├─ seed.js            36 道示例菜
│  └─ icons/             图标
├─ manifest.webmanifest  PWA 配置
├─ sw.js                 Service Worker
├─ serve.py              本地静态服务（会打印手机可用的地址）
├─ 启动.cmd / 停止.cmd    双击启动 / 停止
├─ gen_icons.py          重新生成图标
└─ README.md             本文件
```

Android 外壳工程在仓库外的 `diancai-apk/`：`build.ps1` 一条命令打出签名 APK
（aapt2 + javac + d8 + zipalign + apksigner，不依赖 Gradle）。
